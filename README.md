## ✦ Technical Highlights & Architecture

### 1. 🪐 3D WebGL Liquid Lens Carousel (`flex-carousel.js`)
- Hardware-accelerated WebGL distortion shader using **OGL**.
- Smooth touch, mouse-drag, and wheel-inertia physics.
- Live interactive cards linking to 12 production-deployed web applications.

### 2. 🎡 3D Spatial Drum Reel (`works-wheel.js`)
- Cylindrical 3D perspective drum showcasing **12 verified certificates & credentials**.
- Dynamic card projection maths with interactive lightbox preview on click.

### 3. 🧭 Horizontal Journey Canvas (`experience-section.js`)
- Sticky 100vh spatial viewport translating vertical page scroll into a cinematic timeline of industry internships:
  - **CodSoft** (Frontend Developer Intern)
  - **Prodigy InfoTech** (Web Developer Intern)
  - **Honeybee Digital Solutions LLP** (Backend Developer)

### 4. ⚡ Animated Technical Arsenal
- Glassmorphic competency matrix covering **Frontend Mastery**, **Backend Architecture**, **Databases & Cloud**, and **AI & Developer Tooling**.
- Dynamic micro-interactions with elevation lift and gradient edge glows.

### 5. 📬 Dual Automated Inbound Channels
- **Client Project Inquiries**: Tailored scope selection with direct Web3Forms delivery to Gmail.
- **Recruiter / Hiring Pipeline**: Dedicated hiring proposal modal with instant WhatsApp and email notifications.

## ✦ Getting Started Locally

```bash
# 1. Clone this repository
git clone https://github.com/ShivamDev11/shivam-chauhan-portfolio.git

# 2. Navigate into directory
cd shivam-chauhan-portfolio

# 3. Open in browser directly or run a local server
npx serve .
# or
python -m http.server 3000
```

Open `http://localhost:3000` to view the website.

## ✦ Deployment to Vercel

This is a zero-build static site. You can deploy it instantly on Vercel:

1. Push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your repository and click **Deploy**.
4. No extra build configuration or environment variables required!
